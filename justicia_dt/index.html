Flujo de uso en 5 pasos (§3.3)

1. Abogado selecciona pretensión y subtipo
→
2. Ingresa datos del caso (partes, hechos, cuantía, juzgado, pruebas)
→
3. El DT analiza viabilidad según pretensión
→
4. Simula escenarios what-if
→
5. DT genera análisis, predicciones y recomendaciones

Todo el flujo se ejecuta con un solo llamado: POST /api/flujo_completo
